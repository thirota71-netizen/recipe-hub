# Recipe Hub — iPad / iPhone PWA

レシピ検索・URL取り込み・統一表示を、ホーム画面から起動できるWebアプリにしました。Safariのツールバーを出さずに独立した画面で使えます。App Storeの配布やApple Developer登録は不要です。

## ホーム画面に追加

1. 公開URLをSafariで開き、必要に応じてChatGPTアカウントでサインインします。
2. Safariの共有メニューで「ホーム画面に追加」を選択します。
3. 「Webアプリとして開く」が表示される場合はオンにし、「追加」を押します。
4. ホーム画面のRecipe Hubアイコンから起動します。

サーバーは常時公開されるため、PCを起動しておく必要はありません。ユーザー本人のみがアクセスできる設定です。保存データはD1にあり、同じ公開アプリではiPad・iPhoneから同じレシピを参照できます。

検索・レシピ取り込みにはインターネット接続が必要です。サービスワーカーは画像アイコンと画面用ファイルのみキャッシュし、個人のレシピデータや認証されたHTMLは保存しません。完全オフライン動作は提供しません。

## 機能と制限

材料・調理時間・作り方・出典の統一表示、料理名と食材のAND検索、サイト・時間の絞り込み、調理時間順、URL取り込み、永続保存。

クラシル、DELISH KITCHEN、クックパッド、楽天レシピ、キッコーマン、白ごはん.comの指定ドメインを対象にします。Recipe JSON-LDが公開され、robots.txtで取得が許可されているページだけ対応します。サイトによって情報が取得できない場合があります。実サイトの取得成功はテスト環境で未検証です。

Web横断検索はサーバーの `BRAVE_SEARCH_API_KEY` 設定が必要です。キーなしでもURL取り込みと登録済み検索は使えます。キーは公開ソースに書かず、公開先の秘密の環境変数として設定してください。

## 開発

```sh
npm install
npm run db:generate
npm run build
npm test
```

`worker/index.js` はCloudflare WorkerのAPI、`public/` はPWA画面、`db/schema.ts` はDB定義、`drizzle/` は生成マイグレーションです。ビルドはPWAファイルをWorkerに埋め込み、`dist/server/index.js` を生成します。公開設定は `.openai/hosting.json`。レシピ本文を推測で補わず、欠落値は記載なしと表示します。

## 定期取得

毎朝6時（日本時間）のクラウドタスクが、アプリを閉じていても収集を実行します。キッコーマンとDELISH KITCHENの公開サイトマップから少量ずつ発見し、1回につき各サイト最大4件、合計最大8件を取得します。ほかの掲載サイトは手動URL取り込みに対応しますが、自動巡回には含めません。robots.txtとCrawl-delayを確認し、最低1秒の間隔を空けます。拒否・取得失敗・構造化データ欠落は記録し、認証回避は行いません。

サイトマップの巡回位置と取得待ちURLをD1に保存し、翌日に続きを処理します。成功URLは30日後、失敗URLは7日後に再試行。重複登録は更新になり、同時実行は排他します。日本時間の毎朝6時を区切りとする同じ収集期間内の再実行は、既存の結果を返します。1サイト当たり1回のサイトマップ読取は2ファイルまで、索引は6MBまで、レシピ一覧はストリームで100件ずつ読み、文書の途中位置を保存する保守的な初期設定です。最初から全サイトの全レシピを収集する仕様ではありません。

取得状態は `GET /api/crawl/status`、収集実行は `POST /api/crawl/run`（JSON `{}`）です。本人だけが利用できるSiteのアクセス境界で保護します。未認証の外部公開はしないでください。ルーチン更新はデータだけを変更し、再公開は不要です。

### クラウドタスクからのアクセス

各実行でSitesの `get_site` を呼び、同じSiteがactive・owner・owner-privateであることを確認し、`current_live_url` と返却された `siwc_bypass_bearer_token` を利用します。サービス資格情報はそのSiteにだけ `OAI-Sites-Authorization: Bearer ...` ヘッダーとして送信します。資格情報をソース、ログ、タスク本文に保存しません。公開レシピサイトの読取にはこの資格情報を送信しません。

`node scripts/run-crawl.mjs` を起動し、非表示の標準入力で `{"origin":"確認した公開URL","token":"その実行で取得した資格情報","action":"run"}` を送信します。レスポンス後、`action:"status"` で読戻し、最終実行時刻と件数を確認してください。収集対象と上限はサーバー側で固定し、タスクから任意URLを指示しません。失敗時はエラーを報告し、アクセス制限の回避、対象サイトの拡大、公開範囲の変更を行いません。
